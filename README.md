# People Analytics Portfolio

A curated collection of data engineering, machine learning, and HR analytics projects demonstrating applied statistical modeling, organizational metrics tracking, and predictive workforce planning.

---

## Portfolio Projects

| Project Directory | Focus Area | Core Technologies & Tools | Description |
| :--- | :--- | :--- | :--- |
| **`/employee-attrition/`** | Workforce Turnover | Python, Scikit-Learn, Pandas, Seaborn | Predictive classification models (Logistic Regression & Random Forest) to identify primary drivers of employee turnover. |
| *Coming Soon* | Compensation Equity | Python, SQL, Jupyter | Statistical analysis of pay distributions and internal equity across organizational tiers. |
| *Coming Soon* | Talent Acquisition Funnel | SQL, Pandas, Data Visualization | Pipeline conversion metrics tracking across recruitment stages. |
